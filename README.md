# Transcriptomic-Proteomic Divergence and Early Warning AI in Oral Dysplasia & OSCC

Reproducible Python analysis pipelines accompanying the manuscript:
**"Transcriptomic-Proteomic Divergence Unmasks a Non-Linear Immune Collapse: AI-Driven Detection of the Pre-Malignant Peak in Oral Dysplasia."**

## Repository Contents & Execution Order

Place all scripts and input data files in the same directory (or set the environment variable `OSCC_DATA_DIR` to your data folder), then run in order:

1. **`01_Immune_Collapse_Main_Pipeline.py`**
   - Performs covariate adjustment ($\ln(x+1)$ OLS regression on Age, BMI, and Sex), VIF checks, power analysis, ANOVA/Tukey HSD, Kruskal-Wallis/Dunn's FDR-BH, leakage-free 5-fold out-of-fold all-stage ROC analysis, piecewise BIC trajectory checks, pre-malignant Early Warning AI (Random Forest + nested inner 4-fold Youden threshold tuning + $10 \times 5$ repeated CV + L2 Logistic Regression baseline + TreeSHAP), and cross-platform GSE30784 tissue mRNA validation.
   - **Inputs:** `clean-dataset.xlsx`, `GSE30784_series_matrix.txt`
   - **Outputs:** `processed_synergy_data_final.xlsx` and static/interactive visualizations.

2. **`02_Change_Point_Detection.py`**
   - Fits heuristic natural cubic splines to stage means ($\pm$ SEM) for serum `i-IPS` and tissue `g-IPS`, computes exact analytical first/second derivative extrema, and runs 1,000 stage-stratified bootstrap resamples for peak and monotonicity stability.
   - **Input:** `processed_synergy_data_final.xlsx` (generated by Script 01)
   - **Outputs:** `Functional_Trajectory_Clinical.png`, `Functional_Trajectory_GEO.png`

3. **`03_Correlation_and_Variance_Check.py`**
   - Computes Pearson, Spearman, Kendall's $\tau$, partial correlations, point-biserial correlations, distance correlation (`dCor` with 1,000-resample permutation tests), chi-square permutation checks, hierarchical variance partitioning ($\Delta R^2$), leak-free pre-malignant AIC comparisons, and GSE30784 correlations.
   - **Input:** `processed_synergy_data_final.xlsx` (generated by Script 01)
   - **Output:** `advanced_statistical_results_Raw_and_Processed.xlsx`

4. **`04_Early_Warning_AI_OSCC_Prediction.py`**
   - Standalone, independently executable pre-malignant triage pipeline ($N = 65$; Severe Dysplasia vs. Non-Severe) with leakage-free nested-CV screening cutoffs, $10 \times 5$ repeated CV stability, L2 Logistic Regression benchmarking, calibration plotting, and out-of-fold TreeSHAP attribution.
   - **Input:** `clean-dataset.xlsx`
   - **Outputs:** `early_warning_ai_results.xlsx`, `calibration_curve.png`, `cv_stable_shap_summary.png`, and interactive SHAP HTML plots.


## Input Data Availability & Required Schema

* **Clinical Serum ELISA Dataset (`clean-dataset.xlsx`, $N = 83$ valid samples):** Withheld from this public repository due to institutional ethics and patient privacy policies; available from the corresponding author upon reasonable request and ethics approval. Required columns:
  `Sample No.`, `Sex`, `Age`, `BMI`, `IL-8 Mean`, `sPD-L1 Mean`, `Diagnosis`

* **Public Tissue Microarray Dataset (`GSE30784_series_matrix.txt`, $N = 229$):** Openly available from NCBI Gene Expression Omnibus (GEO):
  - **GEO Accession Page:** [https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE30784](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE30784)
  - **Direct Series Matrix Download:** [https://ftp.ncbi.nlm.nih.gov/geo/series/GSE30nnn/GSE30784/matrix/GSE30784_series_matrix.txt.gz](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE30nnn/GSE30784/matrix/GSE30784_series_matrix.txt.gz)
  - **Setup:** Download `GSE30784_series_matrix.txt.gz`, extract it to `GSE30784_series_matrix.txt`, and place it in the repository root directory (or in the folder specified by `OSCC_DATA_DIR`) before running `01_Immune_Collapse_Main_Pipeline.py`.

## Reproducibility

All stochastic procedures (stratified CV splits, repeated CV splits, Random Forest ensembles, permutation tests, and bootstrapping) use a fixed global seed (`42`).
